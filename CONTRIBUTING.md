# Contributing to DBT-GUARD

Thank you for your interest in contributing to **DBT-GUARD** (Direct Benefit Transfer Beneficiary Resolution Platform).

Developed by **Team NPS** (Christ College of Engineering, Irinjalakuda) for **She Builds Tech 3.0**.

---

## 🌟 18 Key Contributions of DBT-GUARD
1. **Closed-Loop Resolution Lifecycle** - Exit condition requires bank confirmed credit.
2. **12-Rule Triage Engine** - Deterministic mapping to Bank, Akshaya, Revenue, Krishi Bhavan.
3. **Malayalam Voice Assist & IVR** - Spoken vernacular advisory for low-literacy beneficiaries.
4. **4-Stage NIC SMS Simulator** - TRAI DLT and CDAC Mobile Seva testing sandbox.
5. **Multi-Carrier Live Telecom Bridge** - Fast2SMS, Twilio, and WhatsApp links.
6. **Zero-Trust RBAC & DPDP Compliance** - Masked Aadhaar (`XXXX-XXXX-4921`) and tenant isolation.
7. **Browser-First Edge Architecture** - Offline-first React + TypeScript + Zustand in-memory engine.
8. **Automated SLA Aging & Escalations** - District Collector alerts for >7 day bottlenecks.
9. **Tamper-Evident Audit Trail** - Complete chronological log of state changes.
10. **Pre-Filled Resolution Slips** - NPCI Annexure-I Aadhaar-linking mandate generator.
11. **Google Gemini 2.5 Flash Advisory** - Culturally natural Malayalam script generation.
12. **Synthetic 1,000-Case Dataset** - Demographically representative district stress testing.
13. **SLBC Macro Analytics** - Failure clustering to deploy mobile IPPB camps.
14. **Wi-Fi Calling Bridge** - In-app incoming call simulation with Malayalam audio.
15. **Cross-Departmental Evidence Locker** - Unified document verification interface.
16. **Diagnostic Verification Matrix** - Multi-point Aadhaar/NPCI/Land sanity check.
17. **Bilingual i18n Localization** - Real-time Malayalam and English toggle.
18. **Agri-Stack & DigiLocker Ready** - Modular REST endpoints for state portals.

## 🛠️ Contribution Guidelines
- Fork the repository.
- Create your feature branch (`git checkout -b feature/contribution-name`).
- Ensure all TypeScript types pass (`npm run build`).
- Commit changes using conventional commit formats (`feat:`, `fix:`, `docs:`, `perf:`).
- Open a Pull Request for review.
