# Contribution 05: Multi-Carrier Live Telecom Bridge & Fallback Dispatch

## Overview
While the simulator powers offline evaluation, DBT-GUARD includes production-ready connectors to send real notifications to real phones.

## Features
- **Fast2SMS Indian Gateway:** Direct outbound HTTP dispatch to Indian telecom numbers with route bypass and OTP/Service priority.
- **Twilio SMS Gateway:** International standards-compliant SMS fallback.
- **WhatsApp Web Bridge:** Generates pre-filled WhatsApp click-to-chat links with customized Malayalam advisory text.
- **Configurable Recipient Overrides:** Supports instant live testing with evaluator mobile numbers.
