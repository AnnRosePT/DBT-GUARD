# Contribution 14: Wi-Fi Calling Bridge & Interactive Incoming Call Telephony UI

## Overview
Evaluators can experience what the farmer experiences through an interactive simulation of an incoming call.

## Features
- **Realistic Telephony Chime:** Web Audio API synthesizes native Indian phone ring cadences.
- **Caller ID Emulation:** Displays official caller ID `KL-GOVAGR (Govt of Kerala Agriculture Department)`.
- **Audio Synchronization:** Connects to native Malayalam spoken broadcast on call answer.
