# Contribution 03: Native Malayalam Vernacular Voice Assist & IVR Engine

## Overview
Smallholder farmers and senior citizens frequently miss SMS or cannot read technical English/Hindi notifications.

## Key Features
- **Native Malayalam Spoken Audio:** High-quality pre-rendered MP3 broadcasts and Web Speech API synthesis.
- **Accurate Place & Bank Names:** Specially tuned phonetic pronunciation for Kerala panchayats and Malayalam terms.
- **Action-Oriented Scripting:** Focuses on practical instructions (which office to visit, which documents to carry).
