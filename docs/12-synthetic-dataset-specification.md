# Contribution 12: Statistically Grounded 1,000-Beneficiary Synthetic Dataset

## Overview
To validate the system under real-world conditions without exposing live citizen PII, DBT-GUARD includes a realistic 1,000-case synthetic dataset.

## Dataset Profile
- **Geography:** Thrissur District (Ollur, Irinjalakuda, Wadakkanchery, Chalakudy).
- **Distribution:** 750 Ready/Cleared cases, 250 Issue cases mapped across the 12 PFMS failure classes.
- **Realistic Attributes:** Bank IFSCs, land survey parcel IDs, mobile numbers, and aging timelines.
