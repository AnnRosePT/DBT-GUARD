# Contribution 16: Biometric e-KYC & NPCI APBS Diagnostic Engine

## Overview
Disbursement requires 4 prerequisites to align simultaneously: Active Aadhaar, NPCI APBS routing, bank KYC validity, and Land Cadastre linkage.

## Features
- **4-Point Diagnostic Card:** Visually confirms each prerequisite status with green/amber/red indicators.
- **Root-Cause Isolator:** Instantly tells the officer which specific link in the chain is broken.
