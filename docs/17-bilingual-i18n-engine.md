# Contribution 17: Bilingual i18n Localization Engine (English & Malayalam)

## Overview
A public tech platform in Kerala must serve both state bureaucrats (preferring English reports) and grassroots operators and farmers (preferring Malayalam).

## Features
- **Zero-Latency Switcher:** Global Zustand UI store triggers immediate re-renders across all views.
- **Deep Localization:** Includes typography styling with `Noto Sans Malayalam` for proper conjunct ligature rendering.
